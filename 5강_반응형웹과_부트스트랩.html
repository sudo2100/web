1 반응형 웹 디자인

🎯 학습목표
  • 반응형 웹 디자인의 개념과 장단점을 설명할 수 있다.

📖 개념 및 설명

반응형 웹 디자인(Responsive Web Design)은 내용을 그대로 유지하면서 다양한 화면 크기에 맞게 웹사이트를 표시하는 방법이다. 화면 크기에 반응해 요소들을 자동으로 바꾼다.

  • 장점 — 모든 스마트 기기에서 접속 가능, 가로/세로 모드에 맞춘 레이아웃 변경, 사이트 유지·관리 용이(하나의 소스)
  • 단점 — 최신 웹 표준(CSS3)의 일부라서 최신 브라우저에서만 지원

2 뷰포트(Viewport)

🎯 학습목표
  • 뷰포트의 개념을 이해하고 meta 태그로 지정할 수 있다.

📖 개념 및 설명

뷰포트(viewport)는 실제 내용이 표시되는 영역이다. PC와 모바일은 픽셀 표시 방법이 달라, 지정하지 않으면 모바일에서 의도한 대로 표시되지 않는다. 뷰포트를 지정하면 기기 화면에 맞춰 확대/축소해 내용을 표시한다.

<!-- head 태그 안에 작성 -->
<meta name="viewport" content="width=device-width, initial-scale=1">

뜻: 뷰포트 너비를 기기 화면 너비에 맞추고, 초기 배율을 1로 지정.

속성설명 / 값
width뷰포트 너비 — device-width 또는 크기
height뷰포트 높이 — device-height 또는 크기
initial-scale초기 확대·축소 값(1~10)

3 뷰포트 단위 vw·vh

🎯 학습목표
  • 고정 단위(px·%)와 가변 단위(vw·vh)의 차이를 안다.

📖 개념 및 설명

  • px·%는 고정 폰트, vw·vh는 브라우저 비율에 따라 변하는 가변 폰트 단위다.
  • vw(viewport width) — 1vw는 뷰포트 너비의 1%. (너비 1200px이면 5vw = 60px)
  • vh(viewport height) — 1vh는 뷰포트 높이의 1%.
.hero { width: 100vw; height: 50vh; font-size: 5vw; }

4 호스팅과 배포

🎯 학습목표
  • 웹 호스팅의 개념과 종류를 알고, GitHub Pages로 배포할 수 있다.

📖 웹 호스팅

  • 만든 웹 문서를 서버 컴퓨터에 올려야 다른 사람이 접속할 수 있다.
  • 개인은 서버를 직접 마련하기 어려워, 일정 금액을 내고 서버 공간을 빌리는 웹 호스팅 서비스를 이용한다. (cafe24, 고도몰, 가비아 / 무료: 닷홈)
  • 종류 — 윈도우 서버(ASP), 리눅스 서버(톰캣·JSP·PHP), 클라우드 서버(AWS·Google Cloud·MS Azure)

📖 GitHub Pages 무료 호스팅

  • 도메인 주소: https://username.github.io/mysite
  • 설정: 저장소 → Settings → Pages → Branch를 main, 폴더를 /(root)로 선택 → 저장하면 잠시 후 배포됨

5 미디어 쿼리

🎯 학습목표
  • 미디어 쿼리로 화면 크기에 따라 다른 CSS를 적용할 수 있다.

📖 개념 및 설명

미디어 쿼리는 접속 장치에 따라 특정 CSS를 사용하도록 하는 방식으로, 반응형 웹에서 가장 많이 쓰인다.

@media screen and (min-width: 768px) and (max-width: 1400px) {
    .box { background: pink; }
}
미디어 유형설명
all모든 미디어
screen컴퓨터·스마트 기기 스크린
tv음성·영상이 함께 나오는 TV

조건: width·height, min-width·min-height(최소), max-width·max-height(최대)

💡 예제 — 화면 크기에 따라 배경색 바꾸기(mq1.html)
body { background: skyblue; }          /* 모바일 기본 */
@media (min-width: 768px) {
    body { background: pink; }       /* 태블릿 이상 */
}
@media (min-width: 1024px) {
    body { background: lightgreen; } /* PC */
}

브라우저 창 너비를 줄였다 늘였다 하면 배경색이 바뀐다.

✏️ 실습문제

실습 5-1. 모바일에서 요소 숨기기

화면 너비가 800px 미만일 때 사이드바(.side)를 숨기세요.

정답 보기 
@media (max-width: 799px) {
    .side { display: none; }
}

좁은 화면에서 덜 중요한 요소를 display:none으로 숨겨 공간을 확보한다.

6 Flexbox 레이아웃

🎯 학습목표
  • display:flex로 요소를 유연하게 배치·정렬할 수 있다.
  • 주축·교차축 정렬 속성을 사용할 수 있다.

📖 개념 및 설명

플렉스 박스는 수평 또는 수직 하나를 주축으로 정해 박스를 배치하고, 여유 공간이 생기면 너비·높이를 유연하게 늘리거나 줄인다. 배치할 요소를 감싸는 부모(컨테이너)에 display:flex를 준다.

속성설명
display: flex컨테이너를 플렉스 박스로 지정
flex-direction배치 방향 — row(가로) / column(세로)
flex-wrap범위를 넘으면 줄바꿈 — wrap
justify-content주축(수평) 정렬 — center·space-between 등
align-items교차축(수직) 정렬 — center·stretch 등
💡 예제 — justify-content(주축 정렬)
.container {
    display: flex;
    justify-content: space-between;
}

✏️ 실습문제

실습 6-1. 완전 중앙 정렬

컨테이너 안에서 요소를 가로·세로 모두 가운데에 놓으세요.

정답 보기 
.container {
    display: flex;
    justify-content: center;  /* 수평 가운데 */
    align-items: center;      /* 수직 가운데 */
}

이 두 줄이 Flexbox로 완전 중앙 정렬하는 가장 흔한 패턴이다.

7 가변 크기 · calc()

🎯 학습목표
  • max-width·가변 패딩으로 유연한 크기를 만들 수 있다.
  • calc() 함수로 서로 다른 단위를 계산할 수 있다.

📖 개념 및 설명

  • 박스는 %로 가변으로 하되, max-width로 너무 커지지 않게 최대치를 제한한다.
  • calc() — 박스는 가변으로 두되 마진·패딩은 고정하고 싶을 때 사용. 서로 다른 단위를 섞어 계산한다.
.box {
    width: calc(100% - 40px);  /* 전체 너비에서 좌우 20px씩 뺀 값 */
    max-width: 1200px;          /* 최대 1200px까지만 */
}
브라우저 출력 — calc(100% - 40px)
가변이되 좌우 여백은 고정 20px

8 var() — CSS 변수

🎯 학습목표
  • CSS 변수를 정의하고 var()로 재사용할 수 있다.

📖 개념 및 설명

var() 함수는 CSS 변수의 값을 다른 속성 값으로 지정할 때 사용한다. 변수는 :root에 --이름 형태로 정의하며, 색상·크기를 한곳에서 관리할 수 있다.

:root {
    --main: #e64980;   /* 변수 정의 */
    --gap: 16px;
}
.btn {
    background: var(--main);  /* 변수 사용 */
    padding: var(--gap);
}

색을 바꾸고 싶으면 --main 한 줄만 고치면 전체에 반영된다.

📖 참고 — Font Awesome 아이콘

무료 아이콘은 Font Awesome에서 얻는다(get started → 이메일 인증 → 로그인 → 키값(JS 소스) 삽입). 아이콘을 <i> 태그로 손쉽게 넣을 수 있다.

9 부트스트랩 시작하기

🎯 학습목표
  • 부트스트랩이 무엇인지 알고 프로젝트에 연결할 수 있다.

📖 개념 및 설명

부트스트랩(Bootstrap)은 웹사이트를 쉽게 만들도록 돕는 HTML·CSS·JS 라이브러리다. 하나의 CSS로 휴대폰·태블릿·데스크탑까지 작동하는 반응형 웹을 구현할 수 있다.

<!-- 다운로드한 bootstrap.css를 css 폴더에 넣고 연결 -->
<link rel="stylesheet" href="css/bootstrap.css">

연결 후에는 정해진 클래스 이름만 붙이면 스타일이 적용된다.

11 부트스트랩 그리드 시스템

🎯 학습목표
  • 12열 그리드로 반응형 레이아웃을 배치할 수 있다.

📖 개념 및 설명

부트스트랩은 한 행(row)을 12열(column)로 나누는 그리드 시스템을 제공한다(반응형의 필수 기능).

  • <div class="row">는 container 안에 있어야 정상 배열된다.
  • 내용은 col-* 형태로 row의 자식으로 배치한다. 숫자 합이 12가 되게 나눈다.
  • 예: col-6 + col-6 → 6등분씩 2단, col-4 셋 → 3등분
<div class="container">
    <div class="row">
        <div class="col-4">1</div>
        <div class="col-4">2</div>
        <div class="col-4">3</div>
    </div>
</div>

✏️ 실습문제

실습 11-1. 사이드바 + 본문 2단

왼쪽 사이드바를 3칸, 오른쪽 본문을 9칸으로 나누세요.

정답 보기 
<div class="row">
    <div class="col-3">사이드바</div>
    <div class="col-9">본문</div>
</div>

3 + 9 = 12로 한 행을 꽉 채운다.
