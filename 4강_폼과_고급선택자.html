1 폼(Form) 만들기

🎯 학습목표
  • 폼의 역할과 클라이언트-서버 데이터 흐름을 설명할 수 있다.
  • <form>의 action·method 속성을 이해한다.

📖 개념 및 설명

  • 폼(form)은 사용자가 브라우저를 통해 입력한 데이터를 웹 서버로 전송하는 양식이다.
  • 입력된 정보를 처리하는 것은 Java(JSP)·Python·PHP 같은 서버 측 언어이다. (클라이언트 → 폼 데이터 요청 → 서버 → 응답 페이지)
속성설명
action입력 내용을 처리해 줄 서버 경로를 지정
methodget — 주소 표시줄에 입력 내용이 그대로 드러남 / post — 드러나지 않음(보안 필요 시)
name폼의 이름을 지정
<form action="search.jsp" method="get">
    <!-- 여러 폼 요소 -->
</form>

위 예에서 검색어를 입력하고 버튼을 누르면 값이 서버의 search.jsp로 전송되어 검색이 처리된다.

2 input 태그와 type

🎯 학습목표
  • type 속성에 따라 달라지는 다양한 입력 필드를 사용할 수 있다.

📖 개념 및 설명 — input type

<input>은 type 값에 따라 함께 쓰는 속성도 달라진다.

type설명
text한 줄짜리 텍스트 입력 상자
password비밀번호 입력 필드(●●● 처리)
submit입력 내용을 서버로 전송
reset입력 내용 전부 삭제
number숫자 입력(value·min·max·step)
date날짜 선택
radio여러 항목 중 하나만 선택
checkbox여러 항목 다중 선택
file파일 첨부
💡 예제 — 검색 폼(search.html)
<form action="search.jsp">
    <input type="text" name="keyword">
    <input type="submit" value="검색">
</form>
브라우저 출력

실습 2-1. 로그인 입력창

아이디는 텍스트, 비밀번호는 password 타입으로 입력받고 "로그인" 전송 버튼을 두세요.

정답 보기 
<form method="post">
    <input type="text" name="id">
    <input type="password" name="pw">
    <input type="submit" value="로그인">
</form>

비밀번호는 노출되면 안 되므로 method="post"를 쓴다.

3 label · fieldset · legend

🎯 학습목표
  • <label>로 입력창과 설명 텍스트를 연결할 수 있다.
  • <fieldset>·<legend>로 폼 요소를 그룹으로 묶을 수 있다.

📖 개념 및 설명

  • <label> — 입력창 옆에 '아이디'·'비밀번호'처럼 붙여 놓는 텍스트. 화면이 작은 기기에서 라디오·체크박스를 정확히 터치하기 어려울 때 특히 유용하다(라벨을 눌러도 선택됨).
  • <fieldset> — 폼 요소들을 하나의 영역으로 묶어 외곽선을 그린다. <legend> — 그 그룹에 제목을 붙인다.
<fieldset>
    <legend>회원 정보</legend>
    <label for="uid">아이디</label>
    <input type="text" id="uid">
</fieldset>
브라우저 출력
회원 정보

label의 for 값과 input의 id를 같게 하면 라벨 클릭 시 해당 입력창이 활성화된다.

4 radio · checkbox

🎯 학습목표
  • 라디오 버튼과 체크박스의 선택 방식 차이를 안다.

📖 개념 및 설명

  • radio 버튼 — 여러 항목 중 하나만 선택. 같은 그룹은 name 속성 값이 같아야 한다.
  • checkbox — 여러 항목을 다중 선택 가능
<!-- 라디오: name이 같아야 하나만 선택됨 -->
<input type="radio" name="gender" value="m"> 남
<input type="radio" name="gender" value="f"> 여

<!-- 체크박스: 여러 개 선택 -->
<input type="checkbox" name="hobby"> 독서
브라우저 출력
성별(하나만):
취미(여러 개):
✏️ 실습문제

실습 4-1. 라디오 그룹

사과·바나나·포도 중 하나만 고르는 라디오 버튼을 만드세요.

정답 보기 
<input type="radio" name="fruit"> 사과
<input type="radio" name="fruit"> 바나나
<input type="radio" name="fruit"> 포도

name이 모두 fruit로 같아야 셋 중 하나만 선택된다.

5 textarea · select · option

🎯 학습목표
  • 여러 줄 입력과 목록 선택 폼 요소를 사용할 수 있다.
  • <optgroup>으로 옵션을 그룹화할 수 있다.

📖 textarea — 여러 줄 입력

여러 줄 텍스트 입력. cols(글자 수)·rows(줄 수)·placeholder(힌트) 속성을 쓴다.

<textarea cols="30" rows="3" placeholder="내용을 입력하세요"></textarea>

📖 select · option — 목록 선택

목록 형태로 여러 데이터를 나열해 선택한다. <optgroup>은 관련 옵션을 그룹으로 묶는다.

<select>
    <optgroup label="공학">
        <option value="c1">컴퓨터공학</option>
        <option value="c2">전자공학</option>
    </optgroup>
</select>

6 file · hidden · button

🎯 학습목표
  • 파일 첨부·히든 필드·버튼 태그의 용도를 구분한다.

📖 개념 및 설명

요소설명
<input type="file">파일을 첨부할 때 사용
<input type="hidden">사용자에게 보이지 않지만 서버로 값은 전송. <input type="hidden" name="필드" value="값">
<button>버튼. 기본은 전송 기능이 없고 onclick으로 자바스크립트 함수와 함께 쓴다. type="submit"을 명시하면 서버 전송도 가능
<input type="file">
<input type="hidden" name="code" value="A100">
<button onclick="open()">새 창 열기</button>
브라우저 출력
※ hidden 필드는 화면에 나타나지 않는다.

7 input의 다양한 속성

🎯 학습목표
  • readonly·required·autofocus·placeholder 속성을 활용할 수 있다.

📖 개념 및 설명

속성설명
readonly읽기 전용 — 사용자가 수정하지 못하고 읽기만 가능
required필수 필드 — submit 시 값이 비어 있으면 전송을 막고 경고
autofocus페이지가 열리면 해당 필드에 자동으로 커서를 놓음
placeholder입력 힌트를 흐리게 표시하고, 입력을 시작하면 사라짐
<input type="text" placeholder="이름" required autofocus>
<input type="text" value="수정 불가" readonly>
브라우저 출력
✏️ 실습문제

실습 7-1. 필수 이메일 입력

"이메일을 입력하세요" 힌트가 보이고, 비우면 전송되지 않는 이메일 입력창을 만드세요.

정답 보기 
<input type="email" placeholder="이메일을 입력하세요" required>

required가 있으면 값이 없을 때 브라우저가 자동으로 경고를 띄운다.

8 연결 선택자

🎯 학습목표
  • 하위·자식·형제 선택자로 특정 요소만 정교하게 선택할 수 있다.

📖 개념 및 설명

id·class가 많아지면 이름 관리가 복잡해진다. 연결 선택자는 소스의 위치 관계에 따라 특정 요소를 쉽게 선택한다(조합 선택자라고도 함).

선택자설명 · 표기
하위(후손) 선택자부모에 포함된 모든 하위 요소에 적용. 공백으로 구분. section p { }
자식 선택자부모의 직계 자식에만 적용. > 사용. section > p { }
인접 형제 선택자가장 가까운 형제 요소에 적용. + 사용. h1 + p { }
section p   { color: blue; }  /* section 안 모든 p */
section > p { color: blue; }  /* section 직계 자식 p만 */
h1 + p     { color: red; }   /* h1 바로 다음 p */
✏️ 실습문제

실습 8-1. 제목 다음 단락만

<h2> 바로 뒤에 오는 <p>만 진하게(bold) 만드세요.

정답 보기 
h2 + p { font-weight: bold; }

인접 형제 선택자 +는 바로 뒤 하나의 형제에만 적용된다.

9 속성 선택자

🎯 학습목표
  • 속성·속성값을 기준으로 요소를 선택할 수 있다.

📖 개념 및 설명

[속성] 선택자는 지정한 속성(또는 속성값)을 가진 요소를 찾아 스타일을 적용한다. 폼 요소를 type별로 꾸밀 때 특히 유용하다.

input[type="text"]     { border: 1px solid green; }
input[type="password"] { background: #f1f3f5; }
a[target="_blank"]     { color: crimson; }
브라우저 출력

10 가상(클래스) 선택자

🎯 학습목표
  • 사용자 동작·UI 상태에 반응하는 가상 클래스를 사용할 수 있다.

📖 개념 및 설명

가상 클래스 선택자는 지정하기 어려운 웹 요소를 선택하며, 이름 앞에 콜론(:)을 붙인다.

표기설명
:link방문하지 않은 링크
:visited방문한 링크
:hover마우스 커서를 올려놓았을 때
:active클릭해서 활성화됐을 때
:focus초점이 맞춰졌을 때(탭 키 등)
:enabled / :disabled사용할 수 있을 때 / 없을 때
:checked라디오·체크박스가 선택됐을 때

※ 링크 관련은 :link → :visited → :hover → :active 순서로 써야 제대로 적용된다.

a:hover { color: orange; text-decoration: underline; }
브라우저 출력 — 마우스를 올려보세요 이 링크에 마우스를 올리면 색이 바뀝니다
✏️ 실습문제

실습 10-1. 버튼 hover 효과

버튼에 마우스를 올리면 배경색이 진해지도록 만드세요.

정답 보기 
button       { background: #0ca678; }
button:hover { background: #087f5b; }

11 구조 가상 선택자

🎯 학습목표
  • 문서 구조상 특정 위치의 요소를 선택할 수 있다.

📖 개념 및 설명

종류설명
:first-child부모 안 첫 번째 자식 요소
:last-child부모 안 마지막 자식 요소
:nth-child(n)부모 안 n번째 자식 요소
:nth-last-child(n)끝에서 n번째 자식 요소
A:first-of-typeA 요소 중 첫 번째
A:nth-of-type(n)A 요소 중 n번째
li:first-child    { color: green; }
li:nth-child(2n)  { background: #e6fcf5; } /* 짝수 번째 */
브라우저 출력 — nth-child(2n)로 짝수 줄 강조
  1. 첫 번째 (first-child)
  2. 두 번째
  3. 세 번째
  4. 네 번째
✏️ 실습문제

실습 11-1. 표의 홀수 행 줄무늬

표의 홀수 번째 행에만 연한 배경색을 넣으세요.

정답 보기 
tr:nth-child(2n-1) { background: #f1f3f5; }
/* 2n-1 = 1,3,5... 홀수 번째 (2n+1도 가능) */

이런 줄무늬(zebra) 스타일은 표 가독성을 크게 높인다.
