1 배열(Array)

🎯 학습목표
  • 배열의 필요성과 장점을 설명할 수 있다.
  • 배열을 생성하고 인덱스로 접근할 수 있다.

📖 개념 및 설명

  • 학생 10명의 성적을 num1~num10처럼 변수 10개로 만들면 관리가 어렵다. 배열은 여러 값을 인덱스(순서)로 순차 관리해 효율적이다.
  • 배열은 여러 개의 연속된 값을 저장하는 자료형이다. 인덱스는 0부터 시작한다.
// 방법 1 — 대괄호로 직접 생성
let fruits = ["사과", "바나나", "포도"];

// 방법 2 — Array 객체 사용
let arr = new Array(5);   // 길이 5짜리 배열

console.log(fruits[0]);      // 사과 (첫 번째)
console.log(fruits.length);  // 3 (개수)
콘솔 출력사과
3
✏️ 실습문제

실습 1-1. 배열 순회

과일 배열의 모든 항목을 for문으로 출력하세요.

정답 보기 
let fruits = ["사과", "바나나", "포도"];
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

인덱스는 0부터 length-1까지다.

2 함수의 정의와 호출

🎯 학습목표
  • 함수의 개념을 이해하고 정의·호출할 수 있다.

📖 개념 및 설명

함수(Function)는 특정한 하나의 기능을 수행하는 코드 묶음이다. 중복되는 기능을 함수로 만들어 호출해서 재사용한다.

// 명시적 함수(이름 있음) 정의
function sayHello() {
    console.log("안녕하세요!");
}

sayHello();   // 함수 호출
콘솔 출력안녕하세요!

3 함수의 유형(반환값)

🎯 학습목표
  • 매개변수와 반환값이 있는 함수를 작성할 수 있다.

📖 반환값이 없는 경우 / 있는 경우

매개변수는 함수에 값을 넘겨주는 통로이고, return은 결과 값을 돌려준다.

// 반환값 없음 — 출력만
function greet(name) {
    console.log(name + "님 환영합니다");
}

// 반환값 있음 — return 사용
function add(x, y) {
    return x + y;
}
let sum = add(3, 7);
console.log(sum);
콘솔 출력10

4 익명 함수 · 화살표 함수

🎯 학습목표
  • 익명 함수와 화살표 함수를 작성할 수 있다.

📖 익명 함수(이름 없음)

let hello = function() {
    console.log("익명 함수 실행");
};
hello();   // 변수 이름으로 호출

📖 화살표 함수(=>)

함수를 더 짧게 쓰는 문법. 매개변수가 1개면 괄호를 생략할 수 있고, 본문이 return 한 줄이면 중괄호도 생략 가능하다.

const add = (x, y) => x + y;       // return 생략형
const square = x => x * x;          // 매개변수 1개
const hi = () => console.log("hi");  // 매개변수 없음

console.log(add(2, 3));
console.log(square(5));
콘솔 출력5
25

실습 4-1. 짝수/홀수 판별 화살표 함수

숫자를 받아 "짝수"/"홀수"를 반환하는 화살표 함수를 만드세요.

정답 보기

console.log(evenOdd(4));   // 짝수

5 전역 · 지역 변수(스코프)

🎯 학습목표
  • 지역 변수와 전역 변수의 유효 범위를 구분한다.

📖 개념 및 설명

구분유효 범위
지역 변수함수나 제어문의 코드 블록 { } 내부에서 생성되고, 블록을 벗어나면 소멸(스택에서 해제)
전역 변수메인 영역에서 생성되어 전체에 영향을 주고 값을 공유. 프로그램 종료 시 소멸
let g = "전역";          // 전역 변수
function test() {
    let local = "지역";   // 지역 변수
    console.log(g, local);
}
test();
// console.log(local);  // ❌ 오류! 함수 밖에서는 못 씀

지역 변수는 함수 안에서만 유효하다. 전역 변수 남용은 예상치 못한 값 변경을 부를 수 있어 주의한다.

6 객체와 내장 객체

🎯 학습목표
  • 객체의 개념과 내장 객체(DOM·BOM)를 이해한다.

📖 개념 및 설명

  • 객체(Object) — 프로그램에서 인식할 수 있는 모든 대상. 데이터를 저장·처리하는 기본 단위.
  • 내장 객체 — 자바스크립트가 미리 제공하는 객체
    • DOM(문서 객체 모델) — 문서와 그 안의 이미지·링크·텍스트필드를 객체로 관리
    • BOM(브라우저 객체 모델) — 웹 브라우저 정보를 객체로 관리
  • 사용자 정의 객체 — 여러 자료형을 포함하는 복합 자료형을 직접 만드는 것. 객체지향에서는 클래스가 설계도 역할을 한다.

7 Math 객체

  • Math 객체의 함수로 수학 연산·난수를 만들 수 있다.

📖 개념 및 설명

함수설명
Math.abs(x)절대값
Math.round(x)반올림(정수 반환)
Math.floor(x)소수점 이하 버림(정수 반환)

8 Date 객체

🎯 학습목표
  • Date 객체로 날짜·시간 정보를 가져올 수 있다.

📖 개념 및 설명

날짜·시간을 다루는 객체. const date = new Date()로 인스턴스를 만든다.

함수설명
getFullYear()연도(4자리)
getMonth()월(0~11, 0=1월 주의!)
getDate()일(1~31)
getDay()요일(0~6, 0=일요일)
getHours() / getMinutes() / getSeconds()시 / 분 / 초
getTime()1970-01-01 이후 밀리초
const now = new Date();
let year = now.getFullYear();
let month = now.getMonth() + 1;   // +1 필수!
console.log(`${year}년 ${month}월`);
콘솔 출력2026년 8월

getMonth()는 0부터 시작하므로 실제 월을 얻으려면 +1 해야 한다.

9 window 타이머 함수

🎯 학습목표
  • setInterval·setTimeout으로 시간 기반 동작을 만들 수 있다.

📖 개념 및 설명

  • setInterval(함수, 밀리초) — 지정 시간마다 계속 반복 실행(예: 시계)
  • setTimeout(함수, 밀리초) — 지정 시간 후 한 번만 실행
// 1초(1000ms)마다 현재 시각 출력 — 디지털 시계
setInterval(() => {
    let t = new Date();
    console.log(t.toLocaleTimeString());
}, 1000);

// 3초 후 한 번만 실행
setTimeout(() => alert("3초 지났습니다"), 3000);

10 사용자 정의 객체

🎯 학습목표
  • 속성과 메서드를 가진 객체를 만들고 사용할 수 있다.
  • 객체 배열을 다룰 수 있다.

📖 개념 및 설명

객체는 속성(property)과 메서드(function)로 구성된다. 키(key) : 값(value) 형태로 콜론(:)과 콤마(,)를 쓴다.

let person = {
    name: "이정후",          // 속성
    age: 26,
    married: false,
    play: function() {   // 메서드
        console.log("야구를 한다");
    }
};
console.log(person.name);   // 속성 접근
person.play();               // 메서드 호출
콘솔 출력이정후
야구를 한다
💡 예제 — 객체 배열
let members = [
    { name: "하나", age: 20 },
    { name: "두리", age: 22 }
];
for (let m of members) {
    console.log(`${m.name} (${m.age})`);
}
콘솔 출력하나 (20)
두리 (22)
✏️ 실습문제

실습 10-1. 자동차 객체

브랜드·색상 속성과, 정보를 출력하는 메서드를 가진 car 객체를 만드세요.

정답 보기 
let car = {
    brand: "현대",
    color: "흰색",
    info: function() {
        console.log(`${this.brand} / ${this.color}`);
    }
};
car.info();   // 현대 / 흰색

메서드 안에서 자기 객체의 속성은 this.속성으로 접근한다.

11 클래스(class)

🎯 학습목표
  • 클래스로 객체를 생성하는 템플릿을 만들 수 있다.

📖 개념 및 설명

  • 클래스(class)는 객체를 생성하기 위한 템플릿(틀)이다.
  • 구성: 생성자(constructor) · 멤버 변수 · 메서드
  • 멤버 변수 초기화에는 this 키워드를 쓴다.
class Person {
    constructor(name, age) {   // 생성자
        this.name = name;
        this.age = age;
    }
    sayHello() {                // 메서드
        console.log(`안녕하세요, ${this.name}입니다.`);
    }
}

let p = new Person("홍길동", 30);   // 객체 생성
p.sayHello();
콘솔 출력안녕하세요, 홍길동입니다.
✏️ 실습문제

실습 11-1. 원 클래스

반지름을 받아 넓이를 반환하는 메서드 area()를 가진 Circle 클래스를 만드세요.

정답 보기 
class Circle {
    constructor(r) { this.r = r; }
    area() { return Math.PI * this.r * this.r; }
}
let c = new Circle(5);
console.log(c.area().toFixed(2));   // 78.54
콘솔 출력78.54
