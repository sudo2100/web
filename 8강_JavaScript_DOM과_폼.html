1 DOM이란?

🎯 학습목표
  • DOM의 개념과 주요 객체를 설명할 수 있다.

📖 개념 및 설명

DOM(Document Object Model)은 웹 페이지(HTML 문서)를 자바스크립트로 조작할 수 있도록 객체 모델(트리) 형태로 표현한 것이다. DOM을 조작하면 페이지의 구조·내용·스타일·동작을 동적으로 바꿀 수 있다.

주요 객체설명
document웹 페이지 전체를 대표하는 객체
elementHTML 태그 하나하나를 객체로 표현
attribute태그의 속성(id·class 등)
text태그 안의 글자

DOM은 BOM(브라우저 객체 모델)의 window 아래 document로 들어 있다.

2 DOM 요소에 접근하기

🎯 학습목표
  • id·선택자로 DOM 요소를 가져올 수 있다.
  • innerHTML·style로 요소를 바꿀 수 있다.

📖 접근 함수

함수설명
document.getElementById("id")id로 요소 하나 가져오기
document.querySelector("선택자")CSS 선택자로 첫 번째 요소 (#id·.class·태그)
document.querySelectorAll("선택자")조건에 맞는 여러 개 반환

가져온 요소는 innerHTML(내용), style(스타일), src(경로) 등의 속성으로 조작한다.

let box = document.getElementById("display");
box.innerHTML = "내용이 바뀌었습니다!";
box.style.color = "red";

3 이벤트(Event) 종류

🎯 학습목표
  • 마우스·키보드·폼·문서 이벤트 종류를 안다.

📖 개념 및 설명

이벤트(Event)는 브라우저나 사용자가 실행하는 어떤 동작을 말한다.

분류주요 이벤트
마우스onclick(클릭) · mouseover(올림) · mouseout(벗어남)
키보드keydown(누름) · keyup(뗌) · keypress
문서 로딩load(로딩 완료) · scroll(스크롤) · abort
폼change(변경) · focus(커서 놓임) · submit(전송)

4 onclick 이벤트 처리

🎯 학습목표
  • onclick으로 클릭 시 동작을 연결할 수 있다.

📖 개념 및 설명

HTML 태그의 onclick 속성이나 자바스크립트 객체의 onclick 속성에 함수를 연결한다.

<!-- HTML에서 직접 연결 -->
<button onclick="changeBg('green')">Green</button>

// 함수 정의
function changeBg(color) {
    document.body.style.background = color;
}

5 addEventListener()

🎯 학습목표
  • addEventListener로 이벤트 처리기를 연결할 수 있다.

📖 개념 및 설명

한 요소에 여러 이벤트를 연결할 수 있는 함수. 이벤트 유형에는 'on'을 붙이지 않는다(예: click, mouseover).

// 객체.addEventListener(이벤트, 함수)
let btn = document.querySelector("#btn");
btn.addEventListener("click", () => {
    alert("클릭됨!");
});

6 속성 다루기 — get/setAttribute

🎯 학습목표
  • 요소의 속성을 가져오거나 설정할 수 있다.

📖 개념 및 설명

  • getAttribute("속성명") — 속성값 가져오기
  • setAttribute("속성명", "값") — 속성값 설정하기
// 이미지의 src를 바꿔 다른 사진 표시
let img = document.querySelector("#pic");
img.setAttribute("src", "images/big.jpg");
console.log(img.getAttribute("src"));

7 classList 속성

🎯 학습목표
  • classList로 클래스를 추가·삭제·토글할 수 있다.

📖 개념 및 설명

classList는 요소의 CSS 클래스 이름을 다룬다. 클래스를 추가·삭제하며, 반응형 헤더 메뉴 토글 등에 자주 쓴다.

let el = document.querySelector("#menu");
el.classList.add("active");      // 추가
el.classList.remove("active");   // 삭제
el.classList.toggle("active");   // 있으면 빼고 없으면 넣기
라이브 데모 — 클래스 토글

8 노드 추가·삭제

🎯 학습목표
  • 새 노드를 만들어 DOM 트리에 추가할 수 있다.

📖 개념 및 설명

모든 HTML 태그는 요소 노드, 태그 안 텍스트는 텍스트 노드, 속성은 속성 노드가 된다. 이벤트가 발생했을 때 새 노드를 만들어 화면에 추가할 수 있다.

단계 / 함수설명
document.createElement("li")① 요소 노드 만들기
document.createTextNode("텍스트")② 텍스트 노드 만들기
부모.appendChild(자식)③ 자식 노드로 연결(추가)
부모.removeChild(자식)노드 삭제
let li = document.createElement("li");      // ① 요소
let txt = document.createTextNode("새 항목");  // ② 텍스트
li.appendChild(txt);                          // li 안에 텍스트
document.querySelector("ul").appendChild(li); // ③ 목록에 추가

9 폼 요소 접근 — checked

🎯 학습목표
  • 체크박스의 checked 상태로 폼을 제어할 수 있다.

📖 개념 및 설명

체크박스의 checked 속성은 선택 여부(true/false)를 나타낸다. 쇼핑몰에서 "주문자 정보와 배송지 동일" 체크 시 정보를 자동으로 복사하는 데 쓴다.

let chk = document.querySelector("#same");
chk.addEventListener("change", () => {
    if (chk.checked) {   // 체크됐으면 복사
        document.querySelector("#addr2").value =
            document.querySelector("#addr1").value;
    }
});

10 select 옵션 찾기 — onchange

🎯 학습목표
  • 선택 목록에서 사용자가 고른 옵션을 알아낼 수 있다.

📖 개념 및 설명

onchange는 목록·체크 상태가 바뀌면 발생한다. select의 value로 선택된 값을 읽는다.

let sel = document.querySelector("#major");
sel.addEventListener("change", () => {
    console.log("선택: " + sel.value);
});

11 종합 예제 — Todo List

🎯 학습목표
  • 입력·추가·삭제를 결합한 실전 DOM 프로그램을 만들 수 있다.

📖 개념 및 설명

지금까지 배운 요소 접근 + 이벤트 + 노드 추가/삭제를 결합한다. 입력한 할 일을 목록에 추가하고, 각 항목의 삭제 버튼으로 제거한다. (여행 준비물 프로그램도 같은 구조다.)

function addTodo() {
    let val = document.querySelector("#task").value;
    if (val === "") return;              // 빈 입력 방지

    let li = document.createElement("li");
    li.textContent = val;

    let del = document.createElement("button");
    del.textContent = "삭제";
    del.onclick = () => li.remove();   // 자기 항목 삭제

    li.appendChild(del);
    document.querySelector("#list").appendChild(li);
    document.querySelector("#task").value = "";
}

    실습 11-1. Enter로 추가

    입력창에서 Enter 키를 눌러도 항목이 추가되게 하세요.

    document.querySelector("#task").addEventListener("keyup", (e) => {
