1 CSS와 스타일 시트

🎯 학습목표
  • CSS의 역할과 HTML과의 관계를 설명할 수 있다.
  • 스타일 규칙의 형식과 스타일 시트의 세 가지 종류를 구분한다.

📖 CSS(Cascading Style Sheets)란?

  • CSS는 HTML과 함께 웹 표준 기술이다.
  • HTML이 텍스트·이미지·표 같은 요소를 문서에 넣어 뼈대를 만드는 것이라면, CSS는 텍스트 색상·크기, 이미지 크기·위치, 표 색상, 배치 방법 등 웹 문서의 디자인 요소를 담당한다.
  • 웹에서의 스타일(style)은 미리 약속한 스타일 속성을 입력해 웹을 디자인하는 것이다. 내용과 상관없이 디자인만 바꿀 수 있고, 다양한 기기에 맞게 탄력적으로 바뀌는 문서를 만들 수 있다.

📖 스타일 규칙의 형식

스타일은 선택자(태그) { 속성 : 속성값; } 형태로 쓰며, 여러 속성은 세미콜론(;)으로 구분해 중괄호 { } 안에 나열한다.

p {
    font-size: 20px;   /* 속성 : 속성값; */
}

p는 스타일을 적용할 태그(선택자), font-size는 스타일 속성, 20px은 속성값이다.

📖 스타일 시트의 종류

종류설명 · 예시
내부 스타일 시트반드시 <head> 태그 안에 <style>로 작성한다.
<style> p{font-family:궁서체;} </style>
외부 스타일 시트<head> 안에서 별도의 .css 파일을 연결한다.
<link rel="stylesheet" href="./css/style.css">
인라인 스타일내용 중간에 태그와 함께 style 속성으로 쓴다.
<p style="color:blue">블루베리는…</p>
💡 예제 — 세 가지 방식 비교
<!-- ① 내부 스타일 (head 안) -->
<style>
    h1 { color: navy; }
</style>

<!-- ② 인라인 스타일 (태그 안) -->
<p style="color:blue">인라인으로 파랗게</p>
<h1>제목이 남색이 됩니다.</h1>
<p style="color: blue;">인라인으로 파랗게</p>
브라우저 출력

2 글꼴(font) 관련 스타일

🎯 학습목표
  • 글자 크기·모양·굵기·색을 CSS로 지정할 수 있다.
  • px와 em 단위의 차이를 이해한다.

📖 개념 및 설명

종류설명
font-size
글자 크기		px(픽셀) — 고정 크기, 기본 16px / em — 부모 요소 크기 기준의 상대 크기. 예: p{font-size:2em}
font-family
글자 모양		글꼴 지정. 예: body{font-family:궁서}. 구글 웹폰트도 연결해 쓸 수 있다.
font-weight
글자 굵기		굵기 지정. 예: p{font-weight:bold}
color
글자색		① rgb 방식 rgb(0,255,0) ② 16진수 #0000ff ③ 기본색 이름 red
💡 예제 — css_text.html
h2 {
    font-size: 28px;
    font-family: 궁서, serif;
    font-weight: bold;
    color: #d6336c;
}

✏️ 실습문제

실습 2-1. 글꼴 스타일

<h1>의 글자 크기를 2em, 굵기를 굵게, 색을 16진수 파랑(#0000ff)으로 지정하세요.

정답 보기 
h1 {
    font-size: 2em;
    font-weight: bold;
    color: #0000ff;
}
<body>
  <h1>큰 파란 제목</h1>
</body>

2em은 부모 글자 크기의 2배를 뜻한다(부모가 16px이면 32px).

3 웹에서 색상 표현하기

🎯 학습목표
  • 색상 이름·16진수·rgb 세 가지 표기법을 사용할 수 있다.
  • rgba의 알파값으로 불투명도를 조절할 수 있다.

📖 세 가지 색상 표기법

표기법설명
색상 이름기본 색상 이름으로 표시. 기본 16가지(총 216색). 예: color:blue
16진수# 다음 6자리 16진수. 두 자리씩 #RRGGBB. 안 섞이면 00, 가득이면 ff. #000000(검정)~#ffffff(흰색). 두 자리씩 중복이면 축약 가능(#ff00ff → #f0f)
rgb / rgbargb(255,255,0)처럼 세 숫자로 표시(안 섞이면 0, 가득이면 255). 투명도는 rgba(255,0,0,0.5)처럼 마지막에 알파값 추가. a는 0~1(1=완전 불투명, 0=투명)
💡 예제 — 같은 빨강을 세 가지로
.a { color: red; }              /* 이름 */
.b { color: #ff0000; }          /* 16진수 */
.c { color: rgb(255,0,0); }     /* rgb */
.d { color: rgba(255,0,0,0.4); } /* 40% 불투명 */
<p class="a">red</p>
<p class="b">#ff0000</p>
<p class="c">rgb(255, 0, 0)</p>
<p class="d">rgba(255, 0, 0, 0.5)</p>
브라우저 출력

red

#ff0000

rgb(255, 0, 0)

rgba(255, 0, 0, 0.5)

📌 참고 — class 선택자: 문서 안에서 여러 번 반복할 스타일. .(마침표) 다음에 클래스 이름. 예: .btn

✏️ 실습문제

실습 3-1. 반투명 색상

글자색을 파랑에 불투명도 50%로 지정하세요(rgba 사용).

정답 보기 
p { color: rgba(0, 0, 255, 0.5); }
<body>
  <p>반투명 파란 글자입니다.</p>
</body>

알파값 0.5는 50% 불투명(절반 투명)을 뜻한다. #0000ff는 알파값을 넣을 수 없어 rgba를 쓴다.

5 웹 폰트 사용하기

🎯 학습목표
  • 웹 폰트의 개념을 이해하고 구글 웹폰트를 연결해 쓸 수 있다.

📖 개념 및 설명

웹 폰트(Web Font)란 웹 문서 안에 글꼴 정보도 함께 저장했다가, 사용자가 웹 문서에 접속하면 글꼴을 사용자 시스템으로 다운로드시키는 방식이다. 사용자 컴퓨터에 그 글꼴이 없어도 의도한 디자인대로 보인다.

구글 웹폰트(fonts.google.com)에서 'Nanum' 등을 검색 → 코드를 복사해 <head>에 붙여 넣고 font-family로 적용한다.

💡 예제 — webfont.html
<!-- head 안: 구글 웹폰트 연결 -->
<link href="https://fonts.googleapis.com/css2?family=Nanum+Gothic&display=swap" rel="stylesheet">

/* CSS: 폰트 적용 */
body { font-family: "Nanum Gothic", sans-serif; }
브라우저 출력

Web Font

웹 폰트

구글 웹폰트를 사용합니다.

외부 스타일 방식 — HTML(head에서 CSS 파일 연결)

<!-- 외부 스타일 -->
<link rel="stylesheet" href="./css/font.css">
</head>
<body>
  <h2>Web Font</h2>
  <h3>웹 폰트</h3>
  <p>구글 웹폰트를 사용합니다.</p>
</body>

css/font.css

@import url('https://fonts.googleapis.com/css2?family=Nanum+Gothic&display=swap');

body{
    font-family: 'Nanum Gothic', sans-serif;
}

6 선택자(Selector)

🎯 학습목표
  • 전체·태그·id·class·그룹 선택자를 구분해 사용할 수 있다.
  • id와 class의 사용 상황 차이를 안다.

📖 개념 및 설명

스타일 속성을 적용할 대상을 선택자(selector)라고 한다. 태그 하나가 될 수도 있고, 여러 요소를 묶어 별도의 선택자로 지정할 수도 있다.

선택자설명 · 표기
전체 선택자모든 요소에 적용. *(별) 사용. 다른 선택자와 함께 모든 하위 요소에 한꺼번에 적용
태그 선택자특정 태그를 사용한 모든 요소에 적용. 예: p { … }
id 선택자문서 안에서 한 번만 쓰는 스타일. #(샵) 다음에 id 이름. 예: #header
class 선택자문서 안에서 여러 번 반복할 스타일. .(마침표) 다음에 클래스 이름. 예: .btn
그룹 선택자같은 스타일을 쓰는 선택자를 쉼표(,)로 나열해 한꺼번에 정의. 예: h1, h2, p
💡 예제 — selector.css
* { margin: 0; }              /* 전체 선택자 */
p { color: gray; }          /* 태그 선택자 */
#title { color: navy; }     /* id: 한 번만 */
.warn { color: red; }       /* class: 여러 번 */
h1, h2 { font-family: 궁서; } /* 그룹 */
<!-- HTML에서 id / class 지정 -->
<h1 id="title">제목</h1>
<p class="warn">경고 문구</p>
브라우저 출력

제목

경고 문구

✏️ 실습문제

실습 6-1. id와 class 구분

페이지에 한 번만 나오는 로고에는 어떤 선택자를, 여러 버튼에 반복 적용할 스타일에는 어떤 선택자를 쓰는 것이 맞는지 CSS로 보이세요.

9 표(table)를 만드는 태그

🎯 학습목표
  • 행·열·셀의 개념과 표 기본 태그를 사용할 수 있다.
  • 셀 병합·캡션·표 구조 태그를 이해한다.

📖 개념 및 설명

표는 행(row)·열(column)·셀(cell)로 구성된다.

태그설명
<table>~</table>표 전체
<tr>~</tr>행(table row)
<td>~</td>셀/열(table data). 제목 셀은 <th>
<caption>표 제목(캡션)을 넣는다.
💡 예제 — table-1.html / table-caption.html
<table border="1">
    <caption>성적표</caption>
    <tr><th>과목</th><th>점수</th></tr>
    <tr><td>국어</td><td>90</td></tr>
</table>
브라우저 출력
성적표
과목점수
국어90

📖 셀 합치기 · 표 구조 정의

  • 셀 병합 — rowspan: 행 합치기 / colspan: 열 합치기 (width·height로 크기 지정)
  • 표 구조 태그 — <thead>(제목) · <tbody>(본문) · <tfoot>(요약)로 나누면, 시각 장애인도 화면 판독기로 표 구조를 쉽게 이해할 수 있다.
<td colspan="2">두 열을 하나로</td>
<td rowspan="2">두 행을 하나로</td>

10 표(table) 스타일

🎯 학습목표
  • 표의 크기·테두리·여백을 CSS로 꾸밀 수 있다.
  • border-collapse로 테두리선을 하나로 합칠 수 있다.

📖 개념 및 설명

종류설명
width / height
크기		표의 너비 width:300px, 높이 height:100px
border
테두리		굵기 border-width:1px, 스타일 border-style:solid, 색상 border-color:blue. 통합 border-collapse:collapse. 한 번에: border:1px solid #ccc
padding
안쪽 여백		셀의 테두리와 내용 사이의 여백. 예: padding:10px
💡 예제
table { width: 300px; border-collapse: collapse; }
td {
    border: 1px solid #ccc;
    padding: 10px;
}
브라우저 출력
여백 있는 셀B
CD

border-collapse:collapse가 없으면 셀마다 테두리가 두 줄로 겹쳐 보인다.

<thead> ,<tbody>, <tfoot> — 표 구조 정의

  • 표의 구조를 제목 부분과 실제 본문 그리고 요약 부분으로 나눈다.
  • 시각 장애인도 화면 판독기를 통해 표의 구조를 쉽게 이해할 수 있다.
💡 예제 — thead·tbody·tfoot
<table>
  <caption>월별 저축액</caption>
  <thead>
    <tr><th>월별</th><th>저축액</th></tr>
  </thead>
  <tbody>
    <tr><td>8월</td><td>300000</td></tr>
    <tr><td>9월</td><td>400000</td></tr>
  </tbody>
  <tfoot>
    <tr><td>합계</td><td>700000</td></tr>
  </tfoot>
</table>

월별 저축액

Education

<body>
<h1>Education</h1>

11 배경(background) 스타일

🎯 학습목표
  • 배경색과 배경 이미지를 지정할 수 있다.
  • 배경 이미지의 반복·위치·크기를 조절할 수 있다.

📖 배경 색상 · 이미지 속성

종류설명
background-color배경색 스타일. 예: background-color:#222. 이름·16진수·rgb 모두 가능
background-image배경에 이미지 넣기. url() 함수 사용. 예: url('images/bg-1.jpg')
background-repeat배경 이미지 반복 방식(아래 표 참고)
background-position배경 이미지 위치. 예: background-position:top right
background-size배경 이미지 크기 조절(아래 표 참고)

📖 background-repeat 값

값설명
repeat화면에 가득 찰 때까지 가로·세로로 반복(기본)
repeat-x창 너비와 같아질 때까지 가로로 반복
repeat-y창 높이와 같아질 때까지 세로로 반복
no-repeat한 번만 표시하고 반복하지 않음

📖 background-size 값

값설명
auto원래 배경 이미지 크기만큼 표시
contain요소 안에 배경 이미지가 비율대로 축소됨
cover배경 이미지로 요소를 꽉 채우고 나머지는 잘림
<크기값> / <백분율>너비·높이를 직접 지정하거나 백분율로 지정. 예: background-size:200px
💡 예제 — bg-image1.html / bg-size.html
body {
    background-color: #00ff00;
    background-image: url('images/bg-1.jpg');
    background-repeat: no-repeat;
    background-position: top right;
    background-size: cover;
}

  <p>body 전체에 배경색과 배경 이미지가 적용됩니다.</p>
</body>

✏️ 실습문제

실습 11-1. 배경 이미지 한 번만 표시

images/logo.png를 배경으로 넣되 반복하지 않고 오른쪽 위에 한 번만 표시하세요.

정답 보기 
body {
    background-image: url('images/logo.png');
    background-repeat: no-repeat;
    background-position: top right;
}
<body>
  <h1>로고 배경</h1>
  <p>오른쪽 위에 로고가 한 번만 표시됩니다.</p>
</body>

no-repeat이 없으면 이미지가 화면 전체에 바둑판처럼 반복된다.
