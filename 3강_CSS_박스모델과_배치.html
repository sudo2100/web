1 CSS 박스 모델

🎯 학습목표
  • 박스 모델의 네 영역(콘텐츠·패딩·테두리·마진)을 설명할 수 있다.
  • width·height로 콘텐츠 영역 크기를 지정할 수 있다.

📖 개념 및 설명

웹 문서에서 내용을 배치할 때는 각 요소를 박스(box) 형태로 구성한다. 박스 모델은 실제 내용이 들어가는 콘텐츠 영역과 테두리(border), 여백(margin·padding)으로 구성된다.

💡 예제 — width-height.html

width·height는 콘텐츠 영역의 크기를 지정한다. px은 고정, %는 브라우저 창 비율에 따라 달라진다.

.box1 { width: 200px; height: 80px; }  /* 고정 크기 */
.box2 { width: 50%;  height: 80px; }  /* 창 비율에 따라 변함 */
브라우저 출력
박스모델 ✕ 127.0.0.1:5500/ch07/width-height.html
박스모델 ✕ 127.0.0.1:5500/ch07/width-height.html

주황(width:50%)은 창이 넓어지면 함께 커지고, 파랑(width:200px 고정)은 창 크기와 상관없이 그대로다.

2 바깥 여백 — margin

🎯 학습목표
  • margin으로 요소 사이의 간격을 조절할 수 있다.
  • 마진 중첩과 margin:0 auto 가운데 정렬을 이해한다.

📖 개념 및 설명

  • 마진(margin)은 현재 요소 주변의 여백으로, 한 요소와 다른 요소 사이의 간격을 조절한다.
  • 네 방향을 개별 지정할 수 있다: margin-top · margin-right · margin-bottom · margin-left
.box {
    margin: 60px;          /* 네 방향 모두 60px */
    margin-top: 30px;      /* 위쪽만 따로 */
}

📖 마진 중첩(margin collapse)

위 요소의 아래 마진과 아래 요소의 위 마진이 서로 만날 때, 더 큰 마진값으로 합쳐지는 것을 마진 중첩이라 한다. 세로(위·아래) 마진만 중첩되고, 가로 마진은 중첩되지 않는다.

예: 위 박스 margin-bottom:30px + 아래 박스 margin-top:20px → 간격은 50px이 아니라 30px(큰 값).

💡 예제 — 마진 중첩 확인
<style>
  div {
    width:200px;   /* 너비 */
    height:100px;   /* 높이 */
    margin:30px;   /* 마진 */
  }
  #box1 {
    background:rgb(0, 77, 243);
  }
  #box2 {
    background:rgb(255, 72, 0);
  }
  #box3 {
    background:rgb(18, 219, 0);
  }
</style>
브라우저 출력

세로로 이웃한 박스의 margin:30px끼리 중첩되어 사이 간격은 60px이 아니라 30px이 된다.

💡 예제 — 가로 배치 (inline-block)
<style>
  div {
    width:200px;   /* 너비 */
    height:100px;   /* 높이 */
    margin:30px;   /* 마진 */
    display:inline-block;   /* 가로로 배치 */
  }
  #box1 {
    background:rgb(0, 77, 243);
  }
  #box2 {
    background:rgb(255, 72, 0);
  }
  #box3 {
    background:rgb(18, 219, 0);
  }
</style>
브라우저 출력

가로로 이웃한 마진은 중첩되지 않아 30px + 30px = 60px 간격이 된다.

📖 가운데 정렬 — margin:0 auto

margin:0 auto는 요소의 너비 값을 뺀 나머지 공간의 좌우 마진을 똑같이 맞춰 요소를 가운데로 정렬한다. (너비가 지정된 블록 요소여야 한다.)

💡 예제 — margin-center.html
.box {
    width:200px;   /* 너비 */
    height:300px;   /* 높이 */
    background:#ff6a00;   /* 배경색 */
    margin:0 auto; /* 마진 - 0 auto 0 auto */
}
브라우저 출력

3 안쪽 여백 — padding

🎯 학습목표
  • padding으로 콘텐츠와 테두리 사이의 여백을 조절할 수 있다.
  • margin과 padding의 차이를 구분한다.

📖 개념 및 설명

패딩(padding)은 콘텐츠 영역과 테두리 사이의 여백이다. 네 방향을 개별 지정할 수 있다: padding-top·right·bottom·left.

margin은 테두리 바깥쪽 여백(요소 사이 간격), padding은 테두리 안쪽 여백(내용과 테두리 간격)이다.

.box {
    border: 1px solid #7048e8;
    padding: 20px;   /* 내용과 테두리 사이 20px */
}
브라우저 출력 — padding 유무 비교
padding: 0
테두리에 딱 붙음
padding: 20px
안쪽 여백 생김
✏️ 실습문제

실습 3-1. 버튼 여백

버튼 안 글자와 테두리 사이에 위아래 10px, 좌우 20px 여백을 주세요.

정답 보기 
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>버튼 여백</title>
    <style>
        .btn {
            padding: 10px 20px;   /* 위아래 10 / 좌우 20 */

</head>
<body>
    <button class="btn">확인</button>
</body>
</html>

값 2개는 위·아래 / 좌·우 순서다. 4개면 위→오른쪽→아래→왼쪽(시계 방향).

4 테두리 — border

🎯 학습목표
  • 테두리의 두께·스타일·색상을 지정할 수 있다.
  • border-radius로 모서리를 둥글게 만들 수 있다.

📖 개념 및 설명

  • 테두리는 두께·스타일·색상으로 구성되며 한 번에 묶어 쓸 수 있다: border: 1px solid blue
  • 개별 속성: border-width(두께) · border-style(solid·dashed·dotted 등) · border-color(색상)
  • 네 방향을 한꺼번에 지정할 때는 순서(top → right → bottom → left)를 지켜야 한다.
.box {
    border-width: 2px;
    border-style: solid;
    border-color: #7048e8;
    /* 위 세 줄 = border: 2px solid #7048e8; */
}

📖 border-radius — 모서리 둥글게

박스 모서리를 다양한 형태로 처리한다. 값이 클수록 더 둥글어지고, 정사각형에 50%를 주면 원이 된다.

.round { border-radius: 20px; }
.circle { border-radius: 50%; }

기본(각짐)
radius:20px
radius:50% (원)
dashed

5 box-sizing

🎯 학습목표
  • content-box와 border-box의 너비 계산 차이를 이해한다.

📖 개념 및 설명 — 박스 너비 기준 정하기

값설명
content-box
(기본)		width를 콘텐츠 영역 너비로만 사용. 실제 차지 너비 = width + padding + border
border-boxwidth를 콘텐츠+패딩+테두리를 포함한 전체 너비로 사용. 지정한 width가 곧 실제 너비

레이아웃 계산이 편해서 실무에서는 border-box를 많이 쓴다.

💡 예제 — box-sizing.html
/* 둘 다 width:150px, padding:20px, border:5px 인데... */
.a { box-sizing: content-box; } /* 실제 너비 = 150+40+10 = 200px */
.b { box-sizing: border-box; }  /* 실제 너비 = 150px 그대로 */
브라우저 출력 — 같은 width:150px
content-box

border-box

구분설명 · 예

7 display · visibility 속성

🎯 학습목표
  • display로 요소의 배치 방식을 바꿀 수 있다.
  • display:none과 visibility:hidden의 차이를 안다.

📖 display 속성

값설명
block블록 레벨로 표시(한 줄 차지). 인라인 요소도 블록처럼 만들 수 있다.
inline인라인 레벨로 표시(나란히). 이미지는 기본이 inline이다.
inline-block나란히 배치되면서도 너비·높이·여백을 가질 수 있다. 가로 메뉴에 유용.
none요소를 화면에서 완전히 사라지게 한다(공간도 차지하지 않음).
💡 예제 — display: block vs inline-block
div{
    width: 100px;
    height: 100px;
    margin: 10px;
    /* display: block; */
    display: inline-block;
}
.box1{background: #00f;}
.box2{background: #0f0;}
.box3{background: #f0f;}
브라우저 출력 — display: block (세로로 쌓임)
브라우저 출력 — display: inline-block (가로로 나란히)
💡 예제 — 가로 메뉴 navbar1.html

    display: inline-block;
    padding: 10px 18px;
    background: #7048e8;
    color: white;
    text-decoration: none;
}

  <nav>
    <a href="#">홈</a>
    <a href="#">소개</a>
    <a href="#">연락처</a>
  </nav>

홈 소개 연락처

실습 7-1. 세로 메뉴를 가로로

목록으로 만든 세로 메뉴의 각 <li>를 가로로 나란히 배치하되 여백을 줄 수 있게 만드세요.

정답 보기 
li { display: inline-block; padding: 8px 14px; }

📖 visibility 속성

visibility:hidden은 요소를 숨기지만 공간은 그대로 유지한다. 반면 display:none은 공간까지 없앤다.

브라우저 출력 — display:none vs visibility:hidden
ABC
visibility:hidden → B 자리 유지
ABC
display:none → B 자리 사라짐
💡 예제 — display1.html (img에 display 적용)
.pic{
    /* img 태그는 기본 수평 배치가 됨 */
    /* 표시하지 않고 숨기기 할때 - none 사용 */
    /* 이미지의 공간도 사라짐 */
    /*display: none;*/

    /* 수직 배치 */
    display: block;
}

<img src="images/cat.jpg" alt="고양이" class="pic">

브라우저 출력 — .pic(고양이)에 display:block → 수직 배치

참고 — 아무 스타일도 없으면 img는 기본 수평(inline) 배치이고, display:none을 주면 이미지와 공간이 모두 사라진다.

💡 예제 — display2.html (img에 visibility 적용)

    /* 이미지의 공간은 유지됨 */

    /* 보이기 할때 - visible 사용 */
    /* visibility: visible; */
}
브라우저 출력 — visibility:hidden → 고양이는 숨지만 자리(공간)는 유지
브라우저 출력 — visibility:visible(주석 해제) → 모두 표시

8 HTML5 시맨틱 레이아웃 태그

🎯 학습목표

📖 개념 및 설명

웹 문서 표준화를 위해 레이아웃을 만들 때 쓰는 주요 태그를 미리 약속했다. 태그만 봐도 어디가 머리말이고 실제 내용인지 직관적으로 알 수 있어 문서 구조를 정확히 이해할 수 있다. (HTML5: 2008년 초안 공개, 2014년 공식 표준 발표, 현재 W3C 관리)

9 float 속성과 레이아웃

🎯 학습목표
  • float로 요소를 좌우로 띄워 배치할 수 있다.
  • clear로 float를 해제하고 2단 레이아웃을 만들 수 있다.

📖 개념 및 설명 — CSS 포지셔닝

포지셔닝은 화면 안에 각 콘텐츠 영역을 어떻게 배치할지 결정하는 것으로, float와 position 속성이 있다. 박스 모델의 여백·테두리까지 포함해 전체 레이아웃이 완성된다.

float 값설명
left요소를 문서의 왼쪽에 띄워 배치
right요소를 문서의 오른쪽에 띄워 배치

float를 쓰면 그 다음 요소들에도 영향을 미치므로, 해제하려면 clear:left | right | both를 쓴다.

💡 예제 — 박스 나란히 배치(float1.html)
div{
    padding: 10px;
    margin: 10px;
    float: left; /* 모든 박스에 float 적용 */
    /*width: 100px;*/ /* 박스 크기 지정 */
    /*display: inline-block;*/ /* float 대신 inline-block 사용 */
}
.box1{
    background: #ff0;
    /* box1의 위치 left가 되고 다음 개체는 그 옆에 위치함 */
    /* float: left; */
}
.box2{background: #f00;}
.box3{background: #0f0;}
.box4{background: #f0f;}
<div class="box1">박스1</div>
<div class="box2">박스2</div>
<div class="box3">박스3</div>
<div class="box4">박스4</div>
브라우저 출력 — 모두 float:left → 한 줄로 나란히

실습 9-1. 오른쪽 사이드바

본문은 왼쪽 70%, 사이드바는 오른쪽 30%로 float 배치하고, 아래 footer에서 float를 해제하세요.

10 position 속성

🎯 학습목표
  • position의 네 가지 값을 구분해 요소를 배치할 수 있다.
  • 부모가 relative일 때 자식 absolute의 기준을 이해한다.

📖 개념 및 설명

요소들을 자유자재로 배치하기 위한 속성. 좌표(top·right·bottom·left)로 위치를 지정한다.

값설명
static기본값. 문서 흐름대로 배치(위치 지정 불가)
relative원래 위치를 기준으로 상대 이동. 이전 요소에 자연스럽게 연결되며 위치 지정 가능
absolute원하는 위치에 배치. 단독이면 브라우저 창 기준, 부모가 relative이면 그 부모 기준
fixed브라우저 창 기준으로 지정 위치에 고정. 스크롤해도 같은 자리에 유지
💡 예제 — relative 부모 + absolute 자식(position-rel_abs.html)
.parent { position: relative; }  /* 기준이 되는 부모 */
.badge {
    position: absolute;
    top: 10px; right: 10px;  /* 부모 기준 우상단 */
}
<body>
  <div class="parent">
    <span class="badge">NEW</span>
    부모(relative) 기준으로 배지 배치
  </div>
</body>
브라우저 출력
NEW 부모(relative) 기준으로 배지 배치

📖 fixed — 화면에 고정

문서 흐름과 상관없이 브라우저 창 기준으로 배치되며, 스크롤해도 같은 위치에 계속 고정된다. 상단 고정 헤더나 '맨 위로' 버튼에 쓴다.

.top-btn {
    position: fixed;
    right: 20px; bottom: 20px;
}

실습 10-1. 카드 우상단 라벨

11 z-index 속성

🎯 학습목표
  • z-index로 겹친 요소의 쌓임 순서를 정할 수 있다.

📖 개념 및 설명

  • 요소가 겹칠 때 쌓는 순서(앞뒤)를 정한다.
  • z-index 값이 클수록 위에 쌓인다.
  • 값을 명시하지 않으면 나중에 나온 요소가 위에 온다(작성 순서대로 쌓임).
  • 보통 position(relative·absolute·fixed)과 함께 써야 적용된다.
.back  { position: absolute; z-index: 1; }
.front { position: absolute; z-index: 10; } /* 더 위에 */
브라우저 출력
z-index:1
z-index:10

값이 큰 초록 박스가 보라 박스 위에 겹쳐 표시된다.

✏️ 실습문제

실습 11-1. 팝업을 맨 앞으로

다른 모든 요소 위에 항상 뜨는 팝업을 만들려면 어떤 속성을 어떻게 줘야 하는지 쓰세요.

정답 보기 
.popup {
    position: fixed;
    z-index: 9999;   /* 충분히 큰 값 → 항상 맨 앞 */
}
<body>
  <div class="popup">팝업 메시지</div>
</body>

z-index는 position이 static이 아닐 때만 동작한다.
