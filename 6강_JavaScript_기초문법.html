1 JavaScript란?

🎯 학습목표
  • 자바스크립트의 정의·역할·특징을 설명할 수 있다.

📖 개념 및 설명

  • 정의 — 웹 브라우저에서 실행되는 대표적인 스크립트 언어
  • 역할 — 웹 페이지에 동적 기능(Interactive)을 추가 (HTML → 구조, CSS → 디자인, JavaScript → 동작)
  • 역사 — 1995년 넷스케이프의 브렌던 아이크가 10일 만에 개발 → 1997년 ECMAScript 표준화 → 2008년 구글 V8 엔진 → 2009년 Node.js(서버) → 2015년 ES6로 현대 문법 확립
특징설명
인터프리터 언어별도 컴파일 없이 작성하면 바로 실행
브라우저 내장모든 브라우저에서 지원
동적 타이핑타입 지정 없이 실행 시점에 타입 결정
이벤트 기반클릭·입력·마우스 이동 등 이벤트에 따라 실행

2 스크립트 작성과 출력

🎯 학습목표
  • 내부·외부 스크립트를 작성하고, 여러 출력 방법을 쓸 수 있다.

📖 스크립트 작성 방법

// ① 내부 스크립트 — script 태그 안에 작성
<script>
    alert("안녕하세요!");   // 알림창 띄우기
</script>

// ② 외부 스크립트 — 별도 js 파일 연결
<script src="js/main.js"></script>

📖 출력 방법

  • alert() — 알림창 띄우기
  • document.write() — 웹 페이지에 직접 출력
  • console.log() — 개발자 도구(F12) → Console 창에 출력 (디버깅에 가장 많이 사용)
console.log("Hello, JavaScript!");
콘솔 출력Hello, JavaScript!

3 변수(Variable)

🎯 학습목표
  • 변수의 개념을 이해하고 선언·초기화할 수 있다.
  • 변수 이름 규칙을 지킬 수 있다.

📖 개념 및 설명

  • 변수는 자료를 저장하기 위한 메모리 공간이며, 메모리 주소 대신 부르는 이름이다.
  • 실행 중에 값을 바꿀 수 있다. var·let 키워드로 선언한다.
let age;              // 선언
age = 27;             // 초기화(값 대입)
let name = "김하나";  // 선언 + 초기화

변수 이름 규칙

  • 숫자로 시작할 수 없고, 공백 불허 (틀린 예: 3box, sky 1234)
  • 영문·한글·숫자·일부 특수문자(_,$)의 결합
  • 대소문자 구별, 예약어(if·for·while 등) 사용 불가
✏️ 실습문제

실습 3-1. 변수 선언

점수를 담는 변수 score에 85를 저장하고 콘솔에 출력하세요.

정답 보기 
let score = 85;
console.log(score);
콘솔 출력85

4 상수와 호이스팅

🎯 학습목표
  • 상수(const)의 특징을 이해한다.
  • var·let·const의 차이(호이스팅·재선언·재할당)를 구분한다.

📖 상수(const)

한번 설정하면 프로그램 종료까지 변경할 수 없는 값. const로 선언하며, 재할당하면 오류가 난다. 관례상 대문자로 쓴다.

const PI = 3.14;
PI = 3;   // ❌ 오류! 상수는 재할당 불가

📖 호이스팅(hoisting)

'끌어올린다'는 뜻으로, 자바스크립트 해석기가 변수 선언을 미리 기억해 두는 것. var는 선언 전에 써도 오류가 나지 않는다(권장하지 않음).

구분선언 전 사용재선언재할당
let오류✗○
const오류✗✗
var오류 없음(호이스팅)○○

현대 자바스크립트에서는 let과 const를 주로 쓴다.

5 자료형(Type)

🎯 학습목표
  • 기본 자료형과 undefined·null·배열·객체를 구분할 수 있다.

📖 개념 및 설명

구분자료형예시
숫자(정수·실수)numberlet age = 16, let cm = 2.54
문자(문자열)stringlet season = "winter"
불리언booleanlet ok = true
배열objectlet a = ["봄","여름"]
객체objectlet d = new Date()
  • undefined — 변수를 선언했지만 아직 값이 할당되지 않은 상태
  • null — 값이 유효하지 않은 경우(의도적으로 '비어 있음'을 표시)
  • 템플릿 리터럴 — 백틱(`)으로 문자열·변수·식을 섞어 하나의 문자열을 만든다
let name = "하나", age = 20;
console.log(`제 이름은 ${name}, 나이는 ${age}살입니다.`);
console.log(typeof age);   // 자료형 확인
콘솔 출력제 이름은 하나, 나이는 20살입니다.
number
✏️ 실습문제

변수 fruit="사과"와 price=1500을 이용해 "사과는 1500원입니다."를 출력하세요.

정답 보기

console.log(`${fruit}는 ${price}원입니다.`);

6 형 변환(Type Conversion)

🎯 학습목표
  • 문자형↔숫자형 변환 함수를 사용할 수 있다.

📖 개념 및 설명

형 변환은 숫자형을 문자형으로, 문자형을 숫자형으로 바꾸는 것이다.

함수기능
Number()불리언·날짜 등을 숫자로 변환
parseInt()문자형 → 정수형
parseFloat()문자형 → 실수형
toString()자료형 → 문자열
let str = "25";
console.log(str + 5);              // "255" (문자 연결)
console.log(parseInt(str) + 5);   // 30 (숫자 덧셈)
콘솔 출력255
30
✏️ 실습문제

실습 6-1. 입력값 더하기

문자열 "10"과 "20"을 숫자로 바꿔 더한 값을 출력하세요.

정답 보기 
console.log(parseInt("10") + parseInt("20"));  // 30

prompt()로 받은 입력값은 항상 문자열이라 계산 전에 형 변환이 필요하다.

7 연산자

🎯 학습목표
  • 산술·대입·비교·논리·삼항 연산자를 사용할 수 있다.
  • ==와 ===의 차이를 안다.

📖 항과 연산자

항(operand)은 연산에 쓰이는 값, 연산자(operator)는 기호다. 예: 3 + 7에서 3·7은 항, +는 연산자. 항의 개수에 따라 단항(n++)·이항(a*b)·삼항((5>3)?'T':'F')으로 나뉜다.

종류연산자
산술+ - * / % (나머지)
증감++(1 증가) --(1 감소)
복합 대입+= -= *= /= %=
비교> >= < <= == != === !==
논리&&(AND) ||(OR) !(NOT)

==는 값만 비교(10 == '10' → true), ===는 값과 자료형까지 비교(10 === '10' → false). 실무에서는 === 사용을 권장한다.

💡 예제 — 삼항(조건) 연산자
let num = 7;
let result = (num % 2 === 0) ? "짝수" : "홀수";
console.log(result);
콘솔 출력홀수
✏️ 실습문제

실습 7-1. 두 조건 모두 만족

나이가 20 이상이고 회원(isMember=true)일 때만 true가 되는 식을 쓰세요.

정답 보기 
let age = 25, isMember = true;
console.log(age >= 20 && isMember);  // true

&&는 두 항이 모두 참일 때만 참이다.

8 조건문 — if

🎯 학습목표
  • if·if~else·else if로 조건에 따라 분기할 수 있다.

📖 개념 및 설명

조건문은 특정 조건에 따라 프로그램 진행이 분기되는 문장이다(if·switch).

if (조건식) {
    실행문;      // 조건이 true일 때
} else if (조건식2) {
    실행문2;     // 조건2가 true일 때
} else {
    실행문3;     // 모두 false일 때
}
💡 예제 — 학점 계산
let score = 85, grade;
if (score >= 90)      grade = "A";
else if (score >= 80) grade = "B";
else if (score >= 70) grade = "C";
else                grade = "F";
console.log(`학점: ${grade}`);
콘솔 출력학점: B
✏️ 실습문제

실습 8-1. 짝수/홀수 판별

변수 n이 짝수면 "짝수", 홀수면 "홀수"를 출력하세요.

정답 보기 
let n = 10;
if (n % 2 === 0) console.log("짝수");
else console.log("홀수");
콘솔 출력짝수

9 조건문 — switch

🎯 학습목표
  • 값에 따라 분기하는 switch~case문을 작성할 수 있다.

📖 개념 및 설명

조건식의 결과가 정수 또는 문자 값이고, 그 값에 따라 실행문이 결정될 때 사용한다. 각 case 끝에는 break를 써서 빠져나온다.

switch (day) {
    case 1:
        console.log("월요일");
        break;
    case 2:
        console.log("화요일");
        break;
    default:
        console.log("기타");
}

break를 빠뜨리면 다음 case까지 이어서 실행되니 주의한다. default는 어떤 case에도 맞지 않을 때 실행된다.

10 반복문 — while

🎯 학습목표
  • while문으로 조건이 만족하는 동안 반복할 수 있다.
  • break로 반복을 빠져나올 수 있다.

📖 개념 및 설명

반복문은 주어진 조건이 만족하는 동안 실행문을 반복 수행한다.

let i = 1;
while (i <= 5) {
    console.log(i);
    i++;              // 증감값 (없으면 무한 루프!)
}
콘솔 출력1
2
3
4
5

반복 중 break를 만나면 즉시 반복문을 빠져나온다.

11 반복문 — for · 이중 for

🎯 학습목표
  • for문의 구조(초기값·조건식·증감)를 이해하고 사용할 수 있다.
  • 이중 for문으로 행·열을 구현할 수 있다.

📖 for문

// for (초기값; 조건식; 증감값)
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

순서: ① 초기값 → ② 조건식 검사 → ③ 실행문 → ④ 증감값 → 다시 ②로. 조건이 false가 되면 종료.

💡 예제 — 1부터 5까지 합
let sum = 0;
for (let i = 1; i <= 5; i++) {
    sum += i;
}
console.log(`합: ${sum}`);
콘솔 출력합: 15
💡 예제 — 이중 for문(구구단 일부)
for (let i = 2; i <= 3; i++) {
    for (let j = 1; j <= 3; j++) {
        console.log(`${i} x ${j} = ${i*j}`);
    }
}
콘솔 출력2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9

바깥 for는 행, 안쪽 for는 열을 만든다. 행·열 구조(구구단·별 찍기)에 쓴다.

✏️ 실습문제

실습 11-1. 5! (팩토리얼)

for문으로 5 × 4 × 3 × 2 × 1을 계산해 출력하세요.

정답 보기 
let result = 1;
for (let i = 1; i <= 5; i++) {
    result *= i;
}
console.log(result);   // 120
콘솔 출력120

곱셈 누적은 초기값을 1로 둔다(0이면 항상 0).
