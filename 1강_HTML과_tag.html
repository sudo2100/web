1 HTML이란?

🎯 학습목표
  • HTML과 하이퍼텍스트·마크업의 개념을 설명할 수 있다.
  • HTML의 역사와 웹의 탄생 배경을 이해한다.

📖 개념 및 설명

HTML(HyperText Markup Language)은 하이퍼텍스트를 마크업하는 언어이며, 현재 버전은 HTML5이다.

  • 하이퍼텍스트(HyperText) : 웹 사이트에서 링크를 클릭해 다른 문서나 사이트로 이동하는 기능
  • 마크업(Markup) : tag(태그)를 사용해 문서에서 어느 부분이 제목이고 본문인지, 어디가 사진이고 링크인지 표시하는 명령어(코드)

📖 HTML의 역사

  • 인물 : 팀 버너스리(Tim Berners-Lee) — '웹의 아버지', 영국의 컴퓨터 과학자
  • WorldWideWeb(월드와이드웹) 하이퍼텍스트 시스템 고안 — CERN(유럽 입자물리연구소)에서 개발
  • URL · HTML · HTTP를 최초로 설계하고, W3C를 창립

👉 오늘날 우리가 보는 모든 웹 페이지는 이 세 가지 약속(주소=URL, 언어=HTML, 전송 규칙=HTTP) 위에서 동작한다.

🎯 학습목표
  • 웹 브라우저와 웹 편집기의 역할을 구분할 수 있다.
  • 대표적인 도구와 웹 브라우저의 발전 과정을 안다.

📖 웹 브라우저(Web Browser)

  • 코드 편집기 : 비주얼 스튜디오 코드(VS Code), 브라켓(Brackets), 메모장(Notepad)

3 HTML 태그와 문서 구조

🎯 학습목표
  • 태그의 구조(여는 태그·닫는 태그·속성)를 설명할 수 있다.
  • HTML 문서의 기본 골격을 직접 작성할 수 있다.

📖 HTML 태그(Tag)

  • 웹 문서의 내용 중 < 와 > 로 묶인 부분을 태그라 한다.
  • 대부분의 태그는 여는 태그와 닫는 태그로 구성된다. 예: <h2>~</h2>, <p>~</p>
  • 태그는 속성(attribute)과 함께 쓸 수 있다. 형식: <태그 속성="속성값" 속성="속성값" …>
<img src="images/first.jpg" width="300" height="350" alt="시계이미지">

img는 태그 이름, src·width·height·alt는 속성, "..." 안은 속성값이다.

📖 문서 구조를 이루는 기본 태그

태그설명
<!DOCTYPE html>현재 문서가 HTML5로 작성된 웹 문서라는 뜻. 문서 유형을 지정한다.
<html>~</html>웹 문서의 시작과 끝을 나타내는 태그
<head>~</head>브라우저가 문서를 해석하는 데 필요한 정보 입력 부분. <meta>(문자 세트 등 문서 정보), <style>(CSS 코드), <title>(제목 표시줄에 표시) 태그 포함
<body>~</body>실제로 웹 브라우저 화면에 나타날 내용

📖 메모장으로 HTML 문서 만들기

  • 메모장(또는 VS Code)에 HTML 코드를 작성한 뒤, 저장할 때 확장자를 .html로 지정한다.
  • 저장한 파일을 더블클릭하거나 웹 브라우저로 열어 결과를 확인한다.
💡 예제 — web1.html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>HTML 기본문서</title>
</head>
<body>
    <h1>웹 개발 기초</h1>
    <hr>
    <p>HTML</p>
    <p>CSS</p>
    <p>자바스크립트</p>
</body>
</html>

실습 1-1. 나를 소개하는 페이지

제목 표시줄에 "내 소개"가 나오고, 화면에는 큰 제목으로 내 이름, 그 아래 단락으로 취미를 한 문장 보여주는 HTML 문서를 작성하세요.

정답 보기 
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>내 소개</title>
</head>
<body>
    <h1>홍길동</h1>
    <p>저는 등산과 독서를 좋아합니다.</p>
</body>
</html>

<title>은 head 안에서 제목 표시줄을 지정하고, 화면에 보이는 내용은 body 안에 넣는다.

4 주석(Comment)

🎯 학습목표
  • 주석의 용도를 이해하고 HTML에서 주석을 작성할 수 있다.

📖 개념 및 설명

  • 주석은 소스 코드에 대해 설명을 붙여 놓은 메모이다.
  • 소스 코드가 번역(컴파일)되거나 해석되지 않는다 — 즉 화면에 나타나지 않는다.
  • 형식: <!-- 설명글 -->
  • VS Code에서는 Ctrl + / 로 빠르게 주석 처리할 수 있다.
<!-- 이 부분은 메인 제목입니다 -->
<h1>환영합니다</h1>

5 텍스트를 덩어리로 묶는 태그

🎯 학습목표
  • 블록(덩어리) 단위 텍스트 태그의 역할을 구분할 수 있다.
  • 제목·단락·줄바꿈·인용을 적절히 사용할 수 있다.

📖 개념 및 설명 — 블록 레벨 태그

태그설명
<h1>~<h6>Headline(제목). 1~6까지 있으며 1이 가장 크고 6이 가장 작다. 예: <h1>제목</h1>
<p>paragraph(단락). 앞뒤에 줄바꿈이 있는 텍스트 덩어리. <p>텍스트</p>
<br>줄바꿈. 줄을 바꿀 위치에 사용한다.
<hr>수평줄(수평선). 주제가 바뀔 때 분위기를 전환한다.
<blockquote>글을 인용할 경우 사용 — 다른 사이트나 블로그의 글
<pre>입력한 그대로(공백·줄바꿈 유지) 화면에 표시하기
💡 예제
<h1>가장 큰 제목</h1>
<h3>중간 크기 제목</h3>
<p>첫 번째 줄<br>두 번째 줄</p>
<hr>
<blockquote>배움에는 끝이 없다.</blockquote>
브라우저 출력

가장 큰 제목

중간 크기 제목

첫 번째 줄
두 번째 줄

배움에는 끝이 없다.

실습 5-1. 제목과 단락

<h2>로 "오늘의 일기"라는 제목을 만들고, <p> 안에서 <br>로 두 줄짜리 문장을 표시하세요.

정답 보기 
<h2>오늘의 일기</h2>
<p>아침에 일찍 일어났다.<br>기분이 상쾌했다.</p>

<br>은 닫는 태그가 없는 빈 태그(empty tag)이며, 단락 안에서 줄만 바꾼다.

6 텍스트를 한 줄로 표시하는 태그

🎯 학습목표
  • 인라인(한 줄) 텍스트 태그로 일부 글자를 강조·꾸밀 수 있다.
  • 블록 태그와 인라인 태그의 차이를 구분한다.

📖 개념 및 설명 — 인라인 태그

태그설명
<strong>, <b>굵게 표시. strong은 '중요함'을 강조하는 의미, b는 단순히 굵게
<em>, <i>이탤릭체(기울임). em은 '강조'의 의미, i는 단순 기울임
<span>줄바꿈 없이 영역 묶기 — 일부 텍스트만 묶어 스타일을 적용할 때. <span>내용</span>
<mark>형광펜 효과 — 형광펜으로 그어 놓은 듯한 효과
<big>, <small>실제 크기보다 약간 크거나 작게 표시
<u>밑줄(underline)
<sub>, <sup>아래 첨자, 위 첨자
<s>취소선
💡 예제 — tag_text.html
<p>이것은 <strong>중요한</strong> 내용입니다.</p>
<p><em>기울여서</em> 강조하고 <mark>형광펜</mark>도 칠합니다.</p>
<p>물 분자는 H<sub>2</sub>O, 넓이는 5m<sup>2</sup> 입니다.</p>
<p><s>10,000원</s> <u>7,000원</u></p>
브라우저 출력

이것은 중요한 내용입니다.

기울여서 강조하고 형광펜도 칠합니다.

물 분자는 H2O, 넓이는 5m2 입니다.

10,000원 7,000원

📖 웹서버 설치 및 실행

  • VS Code 확장 Live Server(Ritwick Dey) 설치 → 소스에서 마우스 우클릭 → Open with Live Server

실습 6-1. 강조와 첨자

"세일! 원래 가격 20,000원 → 할인가 15,000원"을 표현하고, "CO₂ 배출"에서 2를 아래 첨자로 표시하세요.

<p><strong>세일!</strong> 원래 가격 <s>20,000원</s> → 할인가 15,000원</p>

7 목록을 만드는 태그

🎯 학습목표
  • 순서 없는·순서 있는·설명 목록을 구분해 만들 수 있다.
  • type·start 속성으로 목록의 표시 형태를 바꿀 수 있다.

📖 개념 및 설명

태그설명
<ul>, <li>순서 없는 목록. <ul> 안에 <li>로 각 항목 표시. 항목 앞에 작은 원·사각형 같은 불릿(bullet)이 붙는다.
<ol>, <li>순서 있는 목록. <ol> 안에 <li>로 각 항목 표시. 항목 앞에 숫자(1,2,3)나 문자(a,b,c)가 붙는다.
<dl>, <dt>, <dd>설명 목록(description list). '제목(dt)'과 '설명(dd)'이 한 쌍인 목록. 단어/정의, 질문/답 목록에 사용.

📖 목록에 type 설정하기

<ul> 불릿 모양<ol> 번호 종류
type설명type설명
disc(기본)채워진 원 불릿1(기본)숫자
circle비어 있는 원 불릿a / A영문 소문자 / 대문자
square사각점 불릿i / I로마숫자 소문자 / 대문자

☞ start 속성 — 기본은 1부터 시작이며, start를 설정하면 중간 번호부터 시작한다.

💡 예제 — ul-ol-li.html
<ul>
    <li>사과</li>
    <li>바나나</li>
</ul>

<ol type="a">
    <li>준비운동</li>
    <li>본운동</li>
</ol>

<dl>
    <dt>HTML</dt>
    <dd>웹 문서를 만드는 마크업 언어</dd>
</dl>

실습 7-1. 순서 있는 목록

로마숫자 대문자(I, II, III)로 시작하는 "요리 순서" 목록 세 항목을 만드세요.

정답 보기 
<ol type="I">
    <li>재료를 손질한다</li>
    <li>양념을 만든다</li>

</ol>

8 이미지 관련 태그

🎯 학습목표
  • <img> 태그와 주요 속성으로 이미지를 삽입할 수 있다.
  • 이미지 크기 단위와 이미지 파일 형식의 차이를 안다.

📖 이미지 태그

태그설명
<img><img src="경로" 속성="값"> 형식. alt: 이미지를 설명하는 대체 텍스트, width·height: 이미지 크기(너비·높이) 조정
<img src="images/logo.gif" width="200" height="100" alt="회사로고">

<img>는 닫는 태그가 없는 빈 태그다. 이미지가 안 보일 때 alt의 글이 대신 표시된다.

📖 이미지 크기를 표현하는 단위

종류설명
%상대 크기 — 현재 웹 브라우저 창의 너비·높이를 기준으로 크기를 결정
px고정 크기 — 이미지의 너비나 높이를 해당 픽셀 크기만큼 표시

📖 이미지 파일의 종류

파일 형식설명
GIF
Graphic Interchange Format		최대 색상 수 256가지로 적지만 파일 크기가 작다. 아이콘·불릿, 투명 배경이나 움직이는 이미지를 만들 수 있다.
JPG
Joint Photographic Group		사진을 위해 개발된 형식. GIF보다 다양한 색상과 명암을 표현할 수 있다.
PNG
Portable Network Graphics		투명 배경을 만들면서 다양한 색상도 표현. 네트워크용으로 개발되어 최근 많이 사용한다.
SVG
Scalable Vector Graphic		벡터 이미지. 비트맵(gif·jpg)은 크게 확대하면 테두리가 울퉁불퉁해지지만, SVG는 확대·축소해도 그대로 유지된다.

📖 이미지 크기 지정

  • 고정 크기 : width·height에 픽셀 값을 지정한다. 예) width="300" height="350"
  • 상대 크기 : %로 지정하면 브라우저(부모 요소) 너비에 대한 비율로 표시된다. 예) width="30%"
  • <figure>·<figcaption>으로 이미지와 설명(캡션)을 하나로 묶을 수 있다.
💡 예제 — 이미지 크기 지정
<!-- 고정크기 - 350px -->
<figure>
    <img src="image/img_girl.jpg" alt="자켓을 입은 소녀"
         width="300" height="350">
    <figcaption>자켓을 입은 소녀</figcaption>
</figure>
<hr>
<!-- 상대크기 - 브라우저 크기의 50% -->
<img src="image/img_girl.jpg" alt="자켓을 입은 소녀"
     width="30%">
브라우저 출력

실습 8-1. 이미지 삽입

images 폴더의 cat.jpg를 너비 300px로 삽입하고, 대체 텍스트로 "고양이 사진"을 지정하세요.

정답 보기 
<img src="images/cat.jpg" width="300" alt="고양이 사진">

height를 생략하면 원본 비율에 맞춰 자동 조정된다. 투명 배경이 필요하면 PNG를, 움직이는 이미지가 필요하면 GIF를 쓴다.

9 웹과 멀티미디어 (audio · video)

🎯 학습목표
  • 코덱·인코딩·디코딩 개념을 이해한다.
  • <audio>·<video> 태그와 속성으로 미디어를 재생할 수 있다.

📖 HTML5와 비디오 코덱

  • 인코딩(encoding) : 촬영한 원본 비디오를 컴퓨터에서 사용할 수 있는 비디오 파일로 변환
  • 디코딩(decoding) : 비디오 파일의 정보를 가져와 플레이어로 재생하는 과정
  • 비디오 코덱(codec) : 인코딩과 디코딩을 수행. HTML5에서는 브라우저에서 직접 재생할 수 있는 코덱만 허용한다.

📖 멀티미디어 파일의 종류

종류확장자설명
비디오mp4많이 사용하는 비디오 형식으로 웹에서 무료로 사용할 수 있다.
webm화질이 우수하고 무료라서 mp4와 함께 많이 쓴다.
오디오mp3대부분의 음원에서 사용하는 형식으로 무료이다.

📖 <audio>·<video> 태그의 속성

속성설명
controls플레이어 화면에 컨트롤 바를 표시
autoplay오디오·비디오를 자동으로 실행
loop오디오·비디오를 반복 재생
muted소리는 끄고 화면만 재생
width, height비디오 크기 조절
poster비디오를 재생할 수 없을 때 표시하는 이미지
💡 예제 — audio / video
<p><img src="./medias/healing.jpg" alt="폭포"></p>
<!-- controls : 재생기(player), autoplay-자동재생 -->
<audio src="./medias/spring.mp3" controls></audio>
<!-- <audio src="./medias/spring.mp3" autoplay></audio> -->
브라우저 출력 

<video src="./medias/salad.mp4" controls width="600"></video>
<!-- 구글 : 소리없이 자동 재생 autoplay muted,
     반복재생-loop
     동영상 재생이 안될때 사진 표시 - poster -->
<!-- <video src="./medias/salad.mp4" width="600"
     autoplay muted poster="./medias/salad.PNG"></video> -->
브라우저 출력

controls는 재생·정지·음량 등 재생기(player)를 화면에 표시한다. autoplay는 자동 재생(구글 정책상 음소거 muted 필요), loop는 반복 재생, poster는 동영상이 재생되지 않을 때 표시할 이미지다.

10 하이퍼링크와 nav 태그

🎯 학습목표
  • <a> 태그로 텍스트·이미지 링크를 만들 수 있다.
  • target·href 속성과 내부 문서 연결, <nav>를 이해한다.

📖 a 태그 — 하이퍼링크

<a> 태그는 클릭했을 때 다른 페이지로 넘어가는 기능을 가진다.

<!-- 텍스트 링크 -->
<a href="링크할 주소" 속성="속성값">텍스트</a>

<!-- 이미지 링크 -->
<a href="링크할 주소"><img src="이미지 경로"></a>
속성설명
href링크한 문서나 사이트의 주소를 입력한다.
target링크한 내용이 표시될 위치. _blank는 새 창(새 탭)으로 연다. 예: target="_blank"
rel현재 문서와 링크한 문서의 관계를 알려준다. 예: <link rel="stylesheet" href="style.css">
💡 예제 — tag_a.html
<!-- 네이버 사이트로 연결: 하이퍼링크, 새창(탭) 열기: target="_blank" -->
<p>
    <a href="http://www.naver.com" target="_blank">네이버</a>
</p>

<!-- 내부 문서 - 텍스트 태그 페이지로 이동 -->
<p><a href="./tag_text.html">텍스트 태그</a></p>

<!-- 이미지 클릭 웹페이지 연결 -->
<!-- 상대 경로 - 자신을 기준으로 같은 위치 './', 상위 폴더 '../' -->
<a href="https://www.gg.go.kr/" target="_blank">
    <img src="./image/logo.png" width="150">
</a>
브라우저 출력

📖 nav 태그 — 내부 문서 연결(myweb 프로젝트)

구분설명
<nav>페이지(사이트)를 연결하는 링크들의 집합을 정의할 때 사용하는 태그

메인 페이지(main.html)에서 텍스트 태그·목록 태그·이미지 태그·앵커 태그 페이지로 이동하는 메뉴를 <nav> 안에 <a>로 묶어 만든다.

<nav>
    <a href="main.html">Home</a> |
    <a href="text.html">텍스트</a> |
    <a href="list.html">목록</a> |
    <a href="image.html">이미지</a>
</nav>
브라우저 출력
Home | 텍스트 | 목록 | 이미지
